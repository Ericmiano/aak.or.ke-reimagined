# Aak.or.ke Reimagined

lets look at the site aak.or.ke i want to completely overhaul the current design. preliminary reports are that its boring, cluttered, everything is tightly squeezed, the home page has too much happening hence is confusing to use. id like to have the new site have proper structure, design, a professional look, a proper architectural theme. i want the site be designed in a way that would pull focus to whatever content they want to show as well as direct users to ongoing and upcoming events. i also would like it designed with very good seo implemented as i want it to top search engine results, the site would also be a means to convey project and initiatives for the organization with it being able to sshowcase media about events, projects and initiatives. i want the site to be dynamic and animated without having it overly animated
